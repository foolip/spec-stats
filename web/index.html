Spec maintenance health

The WHATWG Living Standards (HTML, DOM, Fetch, URL, Streams and others) are maintained in the open on GitHub by editors and contributors from browser vendors and beyond. These dashboards look at how that maintenance work gets done and who does it, using only public GitHub data.
